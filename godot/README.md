# Godot project (G0 scaffold)

Open `project.godot` with **Godot 4.3+**.

## Input map

| Action | Key |
|--------|-----|
| `unit_cycle` | Tab |
| `move_left` / `move_right` / `move_up` / `move_down` | Arrow keys |
| `end_turn` | Enter / Space |
| `ui_back` | Esc |
| `attack` | A |

Keyboard only (no mouse required for core loop).

## Scenes

- `scenes/title.tscn` — main / title (default run scene)
- `scenes/battle.tscn` — battle placeholder

## Scripts layout

Matches root `plan.md`: `scripts/app`, `render`, `input`, `game`.
